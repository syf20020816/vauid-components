# 布局引擎

Vauid Components 的核心布局引擎，支持多种布局模式，专为音视频会议、远程协作等场景设计。

## 核心特性

- **虚拟布局引擎**：DOM 恒定 + Transform 驱动，布局切换时零重载
- **智能末尾填补**：Transform 计算量从 O(N) 降至 O(1)
- **Web Worker 计算**：布局计算异步执行，不阻塞主线程
- **多端适配**：桌面端/移动端差异化默认参数

## 布局模式

| 模式 | 描述 | 适用场景 |
|------|------|----------|
| **Grid** | 标准网格布局，自动计算最优行列数 | 多人会议、画廊视图 |
| **Focus** | 主视口 + rail 布局 | 演讲者模式、焦点跟踪 |
| **Fullscreen** | 单个实体占满容器 | 全屏查看、沉浸式体验 |
