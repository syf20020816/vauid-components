# ParticipantNum 参会人数

参会人数徽章组件。

## 基础用法

```tsx
export default () => (
  <ParticipantNum count={42} />
);
```

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `count` | `number` | - | 参会人数 |
